YTGifs

Extensão para navegadores Chromium que permite compartilhar GIFs nos comentários do YouTube com outros usuários do YTGifs.

PORTUGUÊS 🇧🇷

COMO FUNCIONA

1. Abra qualquer vídeo do YouTube.
2. Vá até os comentários e clique no botão GIF.
3. Escolha o GIF que deseja enviar.
4. A extensão irá gerar um token parecido com este:

[ytgifs:AJUDKCdjkdkd]

5. Publique seu comentário normalmente.
6. A extensão reconhecerá o token e tentará exibir o GIF escolhido no comentário.

POR QUE USAR TOKENS?

O YTGifs utiliza tokens de texto para identificar os GIFs compartilhados. Em vez de enviar um GIF como anexo nativo para os servidores do YouTube, a extensão publica um identificador em texto que outras instalações do YTGifs podem reconhecer.

IMPORTANTE

Somente usuários com a extensão YTGifs instalada e funcionando corretamente poderão visualizar o GIF. Quem não tiver a extensão verá apenas o token como texto comum.

O YTGifs não depende do suporte nativo do YouTube para anexos de GIF nos comentários. No entanto, mudanças no YouTube ou no navegador podem afetar o funcionamento da extensão.

--------------------------------------------------

ENGLISH 🇺🇸

HOW IT WORKS

YTGifs is a browser extension for Chromium-based browsers that lets you share GIFs in YouTube comments with other YTGifs users.

1. Open any YouTube video.
2. Go to the comments section and click the GIF button.
3. Choose the GIF you want to share.
4. The extension will generate a token similar to this:

[ytgifs:AJUDKCdjkdkd]

5. Post your comment normally.
6. The extension will recognize the token and attempt to display the selected GIF in the comment.

WHY USE TOKENS?

YTGifs uses text tokens to identify shared GIFs. Instead of sending a GIF as a native attachment to YouTube servers, the extension posts a text identifier that other YTGifs installations can recognize.

IMPORTANT

Only users with YTGifs installed and working correctly will be able to see the GIF. Users without the extension will see the token as ordinary text.

YTGifs does not rely on YouTube native GIF attachment support for comments. However, changes to YouTube or the browser may affect the extensions functionality.
